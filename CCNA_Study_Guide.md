## Labs & Hands-On Practice
- [Wireshark](https://www.wireshark.org/) — packet capture and protocol analysis for lab work.
- [Cisco Packet Tracer (NetAcad)](https://www.netacad.com/cisco-packet-tracer) — network simulation for building and testing topologies.
- [pfSense](https://www.pfsense.org/) — open-source firewall/router platform, useful for routing, NAT, and firewall labs.

## Study Tools
- [IP Subnet Calculator (calculator.net)](https://www.calculator.net/ip-subnet-calculator.html) — check subnetting work while practicing.

## Suggested Study Flow
1. Watch "The Best Way To Learn Networking" for study strategy.
2. Go through Professor Messer for fundamentals (OSI/TCP-IP model, cabling, basic concepts).
3. Follow one full CCNA course start to finish (NetworkChuck or Jeremy's IT Lab) — pick one as primary, use the other for topics needing a second explanation.
4. Install Packet Tracer and rebuild every lab topology from the course.
5. Use Wireshark to inspect real traffic for protocols covered (ARP, DHCP, DNS, TCP handshake, etc.).
6. Practice subnetting manually, verify with the subnet calculator until fast and accurate without it.
7. Set up pfSense in a VM/lab for real firewall/routing practice.
8. Drill practice questions from `MultipleChoice 601q.pdf` regularly, not just at the end.
