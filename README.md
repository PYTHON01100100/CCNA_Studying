# CCNA 200-301 Studying

Personal prep repo for the Cisco CCNA 200-301 exam — study resources, course links, lab tools, and reference material.

## Contents

- **[CCNA_Study_Guide.md](CCNA_Study_Guide.md)** — curated list of courses, videos, labs, and tools, plus a suggested study flow from fundamentals to practice questions.
- **[Terminal_Networking_Commands.md](Terminal_Networking_Commands.md)** — quick reference for network troubleshooting commands (ping, traceroute, ipconfig, tcpdump, nslookup/dig, netstat, route, mtr, nmap, telnet, nc).
- **`materials/`** — local PDFs (textbooks, practice questions, course notes), tracked via [Git LFS](https://git-lfs.com/).

## Getting Started

1. Read [CCNA_Study_Guide.md](CCNA_Study_Guide.md) for the recommended study order.
2. Install [Cisco Packet Tracer](https://www.netacad.com/cisco-packet-tracer) and [Wireshark](https://www.wireshark.org/) for hands-on labs.
3. Keep [Terminal_Networking_Commands.md](Terminal_Networking_Commands.md) open as a cheat sheet while working through labs.
4. Drill practice questions from `materials/MultipleChoice 601q.pdf` regularly.

## Note on Materials

Some files in `materials/` (e.g. the Tanenbaum *Computer Networks* textbooks) are copyrighted third-party works kept here for personal study only.
